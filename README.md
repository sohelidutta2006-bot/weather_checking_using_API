# 🌦️ Weather Checker

A simple and user-friendly Weather Checker web application built using HTML, CSS, and JavaScript. It allows users to check the current weather of any city using the WeatherAPI.

## ✨ Features

- 🌍 Search for any city.
- 🌡️ Display the current temperature in Celsius.
- ☁️ Show current weather conditions.
- 🎨 Attractive gradient background and colorful UI.
- ⚠️ Input validation for empty city names.
- 🔄 Fetch real-time weather information using an API.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- WeatherAPI
